# 减脂进度记录

一个本地优先的减脂记录网页，可记录体重、身体围度、每日总摄入和目标对比。

## 本地打开

打开：

```text
file:///Users/rikiland/Documents/New%20project/index.html
```

或直接打开：

```text
file:///Users/rikiland/Documents/New%20project/1-1-1-1-2-2-2/index.html
```

## GitHub Pages

推送到 GitHub 后，在仓库设置里开启 Pages：

- Source：Deploy from a branch
- Branch：main 或 master
- Folder：/root

开启后访问 GitHub Pages 地址即可。
